## Current focus: SeeON

**SeeON** is a CCTV-based safety operations product for nursing homes. The current system runs real-time edge inference and bed-exit detection; fall-event detection and broader response workflows remain under active development.

| Repository | Role |
| --- | --- |
| [SeeON-edge](https://github.com/SeniorAILab/SeeON-edge) | Public edge runtime for real-time video inference and safety-event processing |
| [SeeON-Front](https://github.com/SeniorAILab/SeeON-Front) | Facility-facing web interface |
| [SeeON-Backend](https://github.com/SeniorAILab/SeeON-Backend) | API, persistence, ingress, and deployment automation |

## How we work

- **Field first.** We design around the work nursing-home staff actually need to complete.
- **Evidence before claims.** We separate live capability, measured results, and planned work.
- **Retrofit where practical.** Software should work with the infrastructure facilities already operate.
- **Human responsibility stays visible.** AI supports staff decisions; it does not replace them.
